# Recoil Control V4

Recoil Control V4 is a modern desktop application designed to improve consistency and control in FPS games through advanced customization, presets, and performance-focused tools.

Built with a focus on speed, simplicity, and real user experience — no unnecessary complexity, just results.

---

## 🚀 Features

- 🎯 Advanced recoil control system  
- 🔁 Universal Recoil (PRO/PRO+)  
- 🧠 Humanizer system for more natural input (Lite/PRO/PRO+)  
- 🎮 Per-operator / per-weapon presets  
- ♾️ Unlimited preset configurations  
- 🖥️ Real-time overlay system  
- 🔔 Smart notifications & hotkey controls  
- 🎨 Clean, modern UI with smooth animations  

---

## 💎 Versions

### Free
Basic features with limited access.

### Lite
Includes:
- Driver support  
- Improved stability  
- Safer usage compared to free version  

### PRO
Includes everything in Lite plus:
- Universal Recoil  
- Humanizer PRO 
- Cloud presets  
- Extra features & priority improvements
